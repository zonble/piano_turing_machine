# Piano Turing Machine

Interactive React + TypeScript + Vite prototype based on `docs/plan.md`.

```bash
npm install
npm run dev
```

The app includes the Turing-machine step engine, editable 0/1/blank tape, five built-in programs, play/pause/step/reset controls, tempo, keyboard interaction, live transition highlighting, Tone.js Salamander piano sampling with Web Audio fallback, and a responsive player-piano visual treatment.
